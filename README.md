## 📚 课程结构（16 周实验目录树）

本仓库按 16 周线性组织，每周一个子目录，养成"每周一提交"的版本管理习惯：

```
ncu-week-05/
├── README.md              ← 你正在阅读的入口
├── .gitignore             ← 全语言通用废品清单
├── .vscode/               ← 个人 IDE 配置（按 .gitignore 自动忽略）
├── assets/                ← 图片 / 截图 / 媒体素材
├── docs/                  ← 课程笔记、参考资料、报告
│
├── Week01/   ~   Week04/  ← 早期实验（待补录）
│
├── Week05/                ⭐ 当前所在周
│   └── README.md          ← 本周实验记录
│
├── Week06/   ~   Week15/  ← 中后期实验（按教学进度依次创建）
│
└── Week16/                ← 期末综合大作业 / 课程总结
```

> **ℹ️ 提示**：本仓库于第 5 周初始化，前 4 周的内容如已存在可手动迁移补录；从第 5 周起，每周实验开始前 `mkdir WeekXX` 即可。

## 🧰 快速上手（How to use）

### 克隆仓库

```bash
git clone https://github.com/jyqCherry/ncu-week-05.git
cd ncu-week-05
```

### 每周新开一周

```bash
# 1. 拉取最新
git pull origin main

# 2. 新建本周目录
mkdir Week06
# 把本周实验文件放进 Week06/

# 3. 提交
git add .
git commit -m "Week06: 完成 XXX 实验 - 关键收获 / 遇到的问题"
git push
```

### 推荐 commit 命名

```
Week05: 实验内容 - 关键收获 / 遇到的问题
Docs:  更新 README 说明
Fix:   修复 xxx
```
